LUMORA

your memories your machine.

A local-first photo & video library for archives that stay on your disk — organise a million assets, search by meaning, and keep every byte offline.

View on GitHub Explore features

Google Photos convenience. Zero cloud.

Built for archive and professional users who need filesystem-scale indexing, fast search, and on-device intelligence — without uploading a single frame.

Everything in the library

Phase 1 baseline plus shipped on-device AI — all local.

Library & indexing

  • Import folders recursively; originals stay where they are
  • Watched folders with live add / change / remove
  • Incremental indexing — hash, EXIF, thumbnails
  • Photos and videos in one library
  • Built for large collections (up to 1M assets)
  • Virtualised grid that stays scrollable at scale

Organisation

  • Manual albums — create, rename, drag & drop
  • Tags, favourites, 1–5 ratings, colour labels
  • Timeline by year and month
  • Recently added and recently viewed
  • Home overview of your library
  • Smart collections: Videos, RAW, Screenshots, Selfies, Panoramas
  • Documents & Receipts collections driven by OCR

Search

  • Full-text search (FTS5) across filename, tags, metadata
  • Structured filters — camera:, rating>, before:, after:
  • Natural-language semantic search with on-device CLIP
  • Semantic results blend with FTS instead of replacing it
  • Recent search history in the toolbar and Discover
  • Find text inside screenshots and documents via OCR
  • Search people by name once faces are labelled

On-device intelligence

  • CLIP ViT-B/32 embeddings for “find by description”
  • People view — detect, cluster, name, merge, ignore
  • RapidOCR PP-OCRv4 text extraction into the search index
  • Background inference that never blocks browsing
  • Model registry — install, verify, remove when you want
  • App works fully with zero models installed
  • Derived data (embeddings, faces, OCR) deletable anytime

Duplicates & cleanup

  • Exact duplicates via SHA-256
  • Near-duplicates via perceptual hash clustering
  • Soft trash with 30-day retention
  • Undo / redo for destructive library actions
  • Safer cleanup flows through trash, not permanent delete

Editing & export

  • Rotate, flip, aspect-ratio crop, exposure (±2 EV)
  • Save as replace (with confirmation) or save as copy
  • ZIP export of selected assets
  • Activity log and exports history

Encrypted vault

  • Argon2id key derivation + XChaCha20-Poly1305
  • Recovery code for vault unlock
  • Lock albums and folders behind the vault
  • Encrypted metadata for vaulted content

Settings & control

  • Settings: General, Appearance, Library, AI Features, Privacy, Storage, Performance, Shortcuts, Import & Export, Updates, About
  • Toggles for semantic search, OCR, face recognition, watch folders
  • Storage summary, clear / rebuild cache, optimise database
  • Developer page for diagnostics only — paths, indexer, logs
  • Local-only diagnostic logs — never uploaded
  • Keyboard-first browsing: preview, rate, favourite, select, trash

Nothing leaves the machine

Core features work with zero network. Models download only when you ask. Inference, indexing, search, logs, and crash reports stay on disk. No telemetry. No analytics. No hosted APIs for your photos.

  • On-device ONNX Runtime (CoreML on macOS, CPU elsewhere)
  • User-initiated model downloads with SHA-256 verification
  • Embeddings, faces, and OCR text rebuildable without touching originals
