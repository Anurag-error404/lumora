01 — Library

Index where the files already live

Point LUMORA at folders on disk. Originals stay put; the app builds a fast local index of hashes, EXIF, thumbnails, and blur scores.

  • Recursive import Bring entire trees into one library without relocating files.
  • Watched folders New shots appear as they land — add, change, and remove stay in sync.
  • Photos + videos One grid for both. Video frame thumbs use system ffmpeg when available.
  • Built for scale Incremental indexing and a virtualised grid that stays scrollable on large archives.

03 — Search

Global text-to-image search across your library

The toolbar search spans your entire archive. Start with fast full-text and structured filters. When you install CLIP, type a description in plain language and LUMORA finds matching photos — text-to-image, on-device, blended with FTS instead of replacing it.

  • Library-wide One search box from anywhere in the app — results cover your whole indexed library.
  • Full-text Filename, tags, camera, OCR text, people names, captions, and auto-tags.
  • Filters camera:, rating>, before:, after: and more.
  • Text-to-image “Dog on a beach at sunset” — CLIP embeddings match meaning, not just keywords. No cloud call.
  • History Recent queries in the toolbar and Discover so you can resume a hunt.

04 — Memories

Stories assembled from your library

LUMORA surfaces curated collections on the Home screen and under Discover — built locally from dates, people, and places. No cloud storytelling; just your photos ranked with on-device CLIP when embeddings are available.

  • On this day Photos from past years on today’s calendar date — relive anniversaries and seasons.
  • Weekend trips Clusters from a short date range when you were away — a quick trip recap.
  • Person & place Named people in a location, when faces and GPS EXIF line up.
  • Save as album Turn a memory into a manual album when you want to keep the set.

05 — On-device AI

Intelligence that stays offline

Every model is optional. Install what you need from Settings → AI. Switch backends in the model library. Delete derived data anytime — originals are never required for a reset.

Text-to-image search

CLIP ViT-B/32 — describe a scene, find matching photos library-wide.

OCR

RapidOCR reads screenshots and documents into search.

People

InsightFace clusters faces — front-facing ≥80% only.

Auto-tags

MobileNetV4 ImageNet labels in the info panel and FTS.

Face models may be non-commercial research licences — check Settings before commercial use.

06 — Cleanup

Delete with confidence

Exact copies, near lookalikes, and soft-focus shots are separated so bulk cleanup never mixes with careful review.

  • Exact duplicates Identical SHA-256. Bulk keep-one when you’re sure.
  • Near duplicates Perceptual hash (Hamming ≤ 2). Review each group — no bulk delete.
  • Blurry review Laplacian variance flags soft / out-of-focus frames for optional trash.
  • Soft trash Retention window plus undo / redo for destructive library actions.
Exact · SHA-256 Near · review Blurry · review

07 — Privacy vault

Lock what should stay private

Move sensitive photos and whole albums into the encrypted Locked folder. Keys stay on your machine — ciphertext on disk, even if someone browses the library folder in Finder.

  • Modern crypto Argon2id for key derivation and XChaCha20-Poly1305 for content and metadata.
  • Recovery code A one-time recovery path if you forget the vault password — store it safely offline.
  • Albums & folders Lock individual items or whole collections behind the vault in one place.
  • Local only No cloud unlock, no hosted key escrow — unlock happens entirely on-device.

08 — Places & extras

Where it was shot — without a map server

Browse by place from GPS EXIF using offline reverse geocoding, then tidy shots with light edits and local export history.

  • Places GPS EXIF grouped with bundled GeoNames data — no tile network calls.
  • Light editing Rotate, flip, crop, exposure (±2 EV) — replace or save as copy.
  • Export & history ZIP export, activity log, and local import analytics — never uploaded.

09 — Plugins

Extend LUMORA with your own actions

Run batch workflows on selected photos from a sandboxed JavaScript plugin — rename by date, export web-ready copies, or build your own. No network access. Every plugin is a folder on disk you can read and edit.

  • Discover & install First-party examples in one click, or import a plugin folder from disk.
  • Create & fork Built-in editor with syntax highlighting and lumora.* autocomplete.
  • Auto permissions Capabilities are inferred from your code — no manual permission checkboxes.
  • Selection actions Run from the Plugins menu when photos are selected — with progress and run history.

Nothing leaves the machine

Core features work with zero network. Models download only when you ask. Inference, indexing, search, logs, and diagnostics stay on disk. Sensitive albums can sit in the privacy vault — encrypted at rest. No telemetry. No analytics. No hosted APIs for your photos.

  • Encrypted Locked folder (Argon2id + XChaCha20-Poly1305) with recovery code
  • On-device ONNX Runtime (CoreML on macOS, CPU elsewhere)
  • User-initiated model downloads with SHA-256 verification
  • Embeddings, faces, OCR, and auto-tags rebuildable without touching originals
  • Global CLIP text-to-image search — embeddings stay on disk, no query leaves the machine
  • Memories built locally from dates, people, and places — no cloud storytelling
  • Offline Places reverse-geocode from bundled GeoNames data
  • Sandboxed JavaScript plugins — no network, explicit permissions, local run history
